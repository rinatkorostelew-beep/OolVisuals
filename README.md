# Ool Visuals (Fabric, Minecraft 1.21.11)

Клиентский мод. Убирает: тряску камеры, анимацию тотема, туман, блок на экране,
стрелы в игроке, частицы разрушения. Внутри уже лежит текстур-пак PvP Lite.

Команда `/visuals` открывает настройки: переключатели и настройки Aspect и дистанции удара (сохраняются).

## Сборка с телефона (GitHub)
1. Создай репозиторий на github.com, загрузи в него все файлы из этой папки (папка `.github` обязательна).
2. Вкладка Actions -> build -> Run workflow (или просто сделай commit).
3. Когда сборка закончится, открой её и скачай артефакт OolVisuals (внутри .jar).
4. Положи .jar в папку mods. Нужны Fabric Loader 0.18+ и Fabric API 0.141.1+1.21.11.

Если сборка упала, пришли мне текст ошибки из лога.

## Быстрая установка блоков
В `/visuals` включи «Быстрая установка блоков» и выбери задержку (1-3 тика, в ванили 4).
Зажимаешь кнопку установки, и блоки ставятся один за другим. Работает только с блоками в руке.
Внимание: на многих серверах это считается читом и банится. Используй там, где разрешено.

## Aspect (растяжка картинки)
В `/visuals` включи «Aspect», выбери шаблон (4:3, 5:4, 16:10 ...) или двигай ползунок «Соотношение».
Чем меньше число, тем сильнее растянуто (4:3 = 1.33). Если окно 16:9 (1.78), то 1.33 даёт классическую растяжку.

## Дистанция удара
После удара по игроку под прицелом на 6 секунд показывается расстояние, с которого ты ударил:
зелёный от 2.5 блока, жёлтый от 1.5, красный ближе.

## Автоспринт
Включи «Автоспринт» в `/visuals` или назначь кнопку: Настройки -> Управление -> Движение -> «Автоспринт (вкл/выкл)».
Когда включён, достаточно держать W, и ты бежишь без двойного нажатия. Голод и остальные условия игра проверяет сама.
