# Ool Visuals (Fabric, Minecraft 1.21.11)

Клиентский мод. Убирает: тряску камеры, анимацию тотема, туман, блок на экране,
стрелы в игроке, частицы разрушения. Внутри уже лежит текстур-пак PvP Lite.

Команда `/visuals` открывает настройки (переключатели сохраняются).

## Сборка с телефона (GitHub)
1. Создай репозиторий на github.com, загрузи в него все файлы из этой папки (папка `.github` обязательна).
2. Вкладка Actions -> build -> Run workflow (или просто сделай commit).
3. Когда сборка закончится, открой её и скачай артефакт OolVisuals (внутри .jar).
4. Положи .jar в папку mods. Нужны Fabric Loader 0.18+ и Fabric API 0.141.1+1.21.11.

Если сборка упала, пришли мне текст ошибки из лога.
